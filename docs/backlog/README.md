# Backlog

Spare, fully specced tickets: for a live run that fails, or a room that is ahead. None of
them exists in `v2/base`. Each needs the base (with the redesigned screens) plus the
checkpoints listed here.

| Spec | Needs | What the room sees |
| ---- | ----- | ------------------ |
| [Board view](board-view.md) | base | Drag a card from Open to In progress; the activity log records it |
| [Keyboard shortcuts](keyboard-shortcuts.md) | base (`x` needs 04) | j/k, x, a, s on the list, and a `?` cheat sheet |
| [Live updates](live-updates.md) | base | A second user changes a ticket; the first sees it without a reload |
| [Similar tickets](similar-tickets.md) | 02 | Typing a new ticket's title suggests the ones it duplicates |
| [SLA health for an organization](organization-sla-health.md) | 03 | The organization page shows how its promises are going |
| [Migrate the legacy reports](migrate-legacy-reports.md) | base | A refactor with the existing tests as the safety net |
